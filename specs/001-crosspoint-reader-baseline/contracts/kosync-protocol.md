# Contract: KOReader sync (KOSync) client

Base URL: `serverUrl` from `koreader.json`, empty = `https://sync.crosspointreader.com`; a URL without `://` gets `http://`; trailing slashes stripped. Transport: wolfSSL `SecureHttpClient` with peer verification disabled, 15 s timeout, no redirects. Every call is refused with `NO_CREDENTIALS` when username or password is empty and with `LOW_MEMORY` when free heap < 35,000 bytes or the largest block < 20,000 bytes.

Common headers on auth/get/put: `Accept: application/vnd.koreader.v1+json`, `x-auth-user: <username>`, `x-auth-key: <lowercase hex MD5(password)>`, `Authorization: Basic base64(username:password)`.

| Call | Request | Result mapping |
|------|---------|----------------|
| Authenticate | `GET /users/auth` | 2xx OK; 401 AUTH_FAILED; other SERVER_ERROR; ≤0 NETWORK_ERROR |
| Sign up | `POST /users/create`, JSON `{"username","password":<md5>}` (only `Accept` and `Content-Type` headers; no x-auth or Basic) | 2xx OK; 402 USER_EXISTS; other (incl. 401) SERVER_ERROR |
| Fetch | `GET /syncs/progress/<documentId>` | 204/404 NOT_FOUND; 2xx parse `{progress, percentage, device, device_id, timestamp[, position]}` (JSON_ERROR on failure); 401 AUTH_FAILED |
| Upload | `PUT /syncs/progress`, JSON `{"document","progress","percentage","device":"CrossPoint","device_id":"crosspoint-reader"[,"metadata":{"filename","title","authors"}][,"position":{"pctQ","spine","page","pages"[,"para"][,"xpath"]}]}` | 2xx OK; 401 AUTH_FAILED; other SERVER_ERROR |

- `position` (CrossPoint extension) is sent and parsed only when the base URL equals `https://sync.crosspointreader.com`; `pctQ` 0..1,000,000; `xpath` omitted when empty or > 120 bytes. `metadata` only when Send Document Metadata is on. No client timestamp.
- Document id: Filename mode = MD5 of the basename after the last `/`; Binary mode = MD5 over `min(1024, size−offset)` bytes at offsets 0, 1024, 4096, …, 2^30 (offsets ≥ size skipped). Empty id aborts with "Failed to calculate document hash".
- Uploaded xpointer forms: `/body/DocFragment[N]/body` (chapter start); `/body/DocFragment[N]/body/<tag>[i]/…` (element ancestry to the N-th `<p>`/`<li>`, 1-based sibling indices, namespace prefixes stripped); `/…/p[i]/text()[t].c` (t = non-empty text run index, c = 1-based codepoint count, target = clamp(1..total, ceil(fraction × visible `<p>` codepoints))); `/body/DocFragment[N]/body/p[k]` (byte-count fallback). N = spineIndex + 1.
- Accepted xpointer forms: `DocFragment[N]` (spine N−1 when in range, else by percentage); element steps (ancestries deeper than 16 steps are truncated to their first 16), tags ≤11 chars (a longer tag or an overflowing index disables ancestry mode and falls back to legacy `/p[N]`, body-text or chapter-start modes), `[i]` optional; optional `/text()` or `/text()[t]`; optional `.c` offset (non-digits or overflow → parse failure → percentage); chapter-start forms `…DocFragment[N]`, `…[N].0`, `…]/body`, `…]/body/`, single-step `.0`; bare `…]/body/text()[t].c`. Resolution order: strict ancestry → relaxed (first step at any depth) → bare body text → legacy global `/p[N]`; the resolved visible-codepoint offset maps to a page via the section LUT (first page at the offset for `img`/`image`), else percentage refined by list-item, anchor-id and paragraph LUTs. The rich `position` is used only when the xpointer cannot be resolved and its spine is in range with a cached page count.
- Smart sync: fetch primary id; fetch alternate id and adopt it when the primary is NOT_FOUND or the alternate percentage is higher; both NOT_FOUND → upload; |local − remote| ≤ 0.001 → "Already synced"; local > remote → upload under the primary id; else apply remote. Ask mode: comparison screen or "No remote progress found / Upload current position?".
- Config file: `{cfgVersion:2, username, password_obf, serverUrl, matchMethod:0|1, sendMetadata:bool, syncBehavior:0 Ask|1 Smart}`; a pre-v2 file with credentials and an empty URL is pinned to `https://sync.koreader.rocks:443`; a missing `syncBehavior` defaults to Ask; invalid enums reset (Filename, Ask) with a resave.
